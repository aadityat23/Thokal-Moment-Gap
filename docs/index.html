01 · THE PROBLEM

A degree-sequence gap

For a finite simple graph G, let a(G) be its annihilation number and M1(G) its first Zagreb index. A Cauchy–Schwarz argument produces an upper envelope B(G) for a(G). The project studies how large the integer slack Γ(G) = floor(B(G)) − a(G) can become on n vertices.

02 · MAIN RESULT

Three asymptotic scales

The current manuscript targets the displayed three-term expansion. The connected construction matches the n2/3 and n1/3 terms, while the global sharper upper bound is the principal point undergoing audit.

Γmax(n) = Γconn(n) = n/2 − 3n2/3/4 − 5n1/3/16 + O(1)

03 · PROOF ARCHITECTURE

From moments to one variable

  1. Universal bound. Cauchy–Schwarz gives a(G) ≤ floor(B(G)).
  2. Head/tail parameterization. The annihilation threshold is encoded by h, q, x, U and E.
  3. Scale-free relaxation. Degree variance yields an upper envelope Fn(h,v,r).
  4. Endpoint reduction. The relaxed variables are reduced to a one-variable envelope Φn.
  5. Asymptotic optimization. Strict concavity localizes the continuous maximizer.
  6. Connected sharpness. A universal vertex joined to path components realizes the displayed expansion.
