02

THE QUESTION

How large can the gap become?

For a finite simple graph G, the annihilation number a(G) is defined by the smallest degrees, while the first Zagreb index M1(G) captures a quadratic degree moment.

A Cauchy–Schwarz inequality produces an upper envelope B(G). This project studies the integer slack between that moment bound and the annihilation number.

EXTREMAL CONSTRUCTION

One universal vertex.
Many path components.

The connected construction places a universal vertex over disjoint path components. Its degree sequence takes the form (2n−1, D), giving a concrete family whose gap follows the predicted asymptotic expansion.
