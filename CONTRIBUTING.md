# Contributing

This is a single-author research repository around an unrefereed manuscript. Pull requests that change the mathematics are not expected. Independent scrutiny is welcome.

## Reporting a mathematical problem

Please open an issue if you find an error, a gap, or a counterexample. Useful reports state:

- the location (manuscript section, equation, or lemma in the dossier);
- what is claimed and what fails, ideally identifying the first invalid implication;
- for a counterexample, an explicit graph or degree sequence with $n$, $m$, $M_1$, $a(G)$, and $\Gamma(G)$.

## Other corrections

Typos, notation inconsistencies, and reference errors can be reported the same way or sent as a small pull request against the documentation.
